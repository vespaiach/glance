# Glance PWA icons (concept 7a, Spring)

Background #c8e6cd (mint), frame #000, screen #fff, tiles #efd4d4 / #dceeb1 / #c5b0f4.
The mark sits inside the 80% maskable safe zone, so the maskable files are the same artwork.

Add to <head>:

```html
<link rel="manifest" href="/manifest.webmanifest">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<meta name="theme-color" content="#000000">
```

`_master-1024.png` is the full-resolution source.
