Small-screen drawerNotes →

Small screen 390×844, left navigation, at full size whatever the size picker says. On small screens there is no icon rail: the edge grip opens the full menu drawer in one tap, and closing it returns to the grip. The drawer slides over the page instead of pushing it; a scrim covers the page and tapping it closes the drawer. The drawer is the same on every view; only the current row changes. Event pages (B) open full screen over the drawer and nav, sliding in from the right; actions sit in a bar at the bottom.
